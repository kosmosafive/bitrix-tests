# Установка

```bash
composer require --dev kosmosafive/bitrix-tests
```

## Symfony Console и Bitrix

Bitrix Framework в вашей инсталляции может не поддерживать 7-ю версию `symfony/console`.
Для установки необходимо поднять зависимость в `bitrix/composer-bx.json`.

Если используются консольные команды, скорректируйте классы команд.
Например, в ядре укажите тип возвращаемых данных (`:int`) у метода `execute()` в файлах:

- `bitrix/modules/main/lib/cli/ormannotatecommand.php`
- `bitrix/modules/translate/lib/cli/indexcommand.php`

## Требования

- PHP `^8.3`
- расширение `ext-mysqli`
- Pest `^4.3`

См. также: [Настройка](Настройка).
