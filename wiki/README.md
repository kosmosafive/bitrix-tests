# Wiki

Документация пакета `kosmosafive/bitrix-tests`.

Начните с [Home](Home.md).

Чтобы опубликовать как [GitHub Wiki](https://docs.github.com/en/repositories/working-with-files/using-files/adding-or-editing-wiki-pages):

1. В настройках репозитория включите Wiki (`has_wiki`).
2. Создайте первую страницу в UI GitHub (инициализирует `*.wiki.git`).
3. Скопируйте содержимое этой директории в клон wiki-репозитория и сделайте push.
