# Архитектурное тестирование

Расширение Pest из `\Kosmosafive\Bitrix\Tests\Pest\Expectations`.

## notToUseBannedFunctions

Проверка на использование нежелательных функций.
В параметр можно передать массив функций, которые разрешены.

```php
arch()
    ->expect('Vendor\Example')
    ->notToUseBannedFunctions(['unserialize']);
```

Список запрещённых функций загружается вместе с [Bootstrap](Настройка).
