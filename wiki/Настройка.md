# Настройка

## 1. Директория конфигурации

Создайте директорию для конфигурации тестов (например, `local/tests`) и перейдите в неё.

## 2. Файл `.env`

| Опция | Значение | Пример |
|-------|----------|--------|
| `SITE_ID` | Идентификатор сайта | `s1` |
| `LANGUAGE_ID` | Идентификатор языка | `ru` |
| `LOG_LEVEL` | Уровень логирования, PSR-3 | `error` |
| `RECREATE_TEST_DB` | Принудительно пересоздать схему тестовой БД (`1` / `true` / `yes`) | `1` |

`RECREATE_TEST_DB` используется [неинтерактивным клоном схемы](Тестовая-база-данных) (`TestDatabase`).

## 3. Директория данных

Создайте директорию для файлов тестов (например, `local/tests/.data`).

## 4. `bootstrap.php`

```php
<?php

declare(strict_types=1);

use Kosmosafive\Bitrix\Tests\Bootstrap;

$classLoader = require __DIR__ . '/../vendor/autoload.php';

/**
 * Опционально: автозагрузка для архитектурного тестирования
 */
$autoload = [
    ['Vendor\Example\\', __DIR__ . '/../modules/vendor.example/lib'],
];

(new Bootstrap(
    $classLoader,
    dirname(__DIR__, 2),
    __DIR__ . '/.env',
    __DIR__ . '/.data',
    $autoload
))->initialize();
```

## 5. PHPUnit — `phpunit.xml.dist`

```xml
<?xml version="1.0"?>
<phpunit
        xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
        bootstrap="bootstrap.php"
        colors="true"
        xsi:noNamespaceSchemaLocation="https://schema.phpunit.de/11.3/phpunit.xsd"
        cacheDirectory=".phpunit.cache"
        executionOrder="default"
        defaultTestSuite="coverage"
>
    <testsuites>
        <testsuite name="unit">
            <directory>../modules/*/tests/Unit</directory>
        </testsuite>
        <testsuite name="integration">
            <directory>../modules/*/tests/Integration</directory>
        </testsuite>
        <testsuite name="application">
            <directory>../modules/*/tests/Application</directory>
        </testsuite>
        <testsuite name="architecture">
            <directory>../modules/*/tests/Architecture</directory>
        </testsuite>
        <testsuite name="stress">
            <directory>../modules/*/tests/Stress</directory>
        </testsuite>
        <testsuite name="coverage">
            <directory>../modules/*/tests/Unit</directory>
            <directory>../modules/*/tests/Integration</directory>
        </testsuite>
    </testsuites>
    <source restrictNotices="true">
        <include>
            <directory suffix=".php">../modules/*/lib</directory>
        </include>
    </source>
</phpunit>
```

Добавьте в `.gitignore` директории `.phpunit.cache` и `coverage`.

## 6. Infection — `infection.json5`

```json
{
    "$schema": "../vendor/infection/infection/resources/schema.json",
    "source": {
        "directories": [
            "{modules/*/lib}"
        ]
    },
    "timeout": 10,
    "logs": {
        "text": "infection/infection.log",
        "html": "infection/infection.html"
    },
    "mutators": {
        "@default": true,
        "@function_signature": false
    },
    "bootstrap": "tests/bootstrap.php",
    "testFrameworkOptions": "--testsuite=unit"
}
```

Добавьте в `.gitignore` директорию `infection`.

## 7. Pest — `Pest.php`

Создайте файл `Pest.php`. По умолчанию достаточно пустого файла.

Для интеграционных Pest-тестов наследуйте [`Kosmosafive\Bitrix\Tests\Pest\BitrixTestCase`](Pest).
